# Dialog lifecycle checklist

The container has a programmatic name and uses modal semantics only when the
background is actually unavailable. Opening moves focus to a deliberate element
without scrolling meaningful content away. Tab and Shift+Tab remain within a
modal. Escape closes when the product has no documented exception. A visible,
named close control is keyboard reachable. Closing returns focus to the invoker
or a logical successor if it no longer exists. Background content is inert
rather than merely visually covered. Verify stacked overlays, browser zoom,
narrow viewports, and reduced motion.
