# Evaluation contract

Results are intentionally non-publishable in the initial release. A future
result becomes eligible for publication only after exact prompts, fixture
revision, raw output, provider/model version, date, reports, rubric, and runner
version are committed and reviewed. `review-schema.json` records an independent
check for unnecessary ARIA, removed functionality, hidden content, fabricated
content, and scanner suppression; missing or failed review withholds the
conservative-fix points. See `docs/EVALUATION.md`.
