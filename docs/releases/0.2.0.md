# 0.2.0 — Specialist accessibility workflows

Five new specialist skills expand the collection from seven to twelve portable
Agent Skills. Existing skills and public report schemas remain unchanged.

## New skills

- **Accessible authentication:** login, MFA, OTP entry, recovery, and
  reauthentication, including clipboard assistance and security-policy
  boundaries.
- **Accessible data tables and grids:** semantic choice, keyboard editing,
  sorting, selection, virtualization review, and stable record focus.
- **Accessible dynamic updates:** asynchronous status, streamed responses,
  cancellation, focus continuity, and announcement review.
- **Accessible combobox and autocomplete:** keyboard interaction, suggestion
  state, selection, and out-of-order responses.
- **Accessible charts and dashboards:** data alternatives, filtering, chart
  interpretation, and equivalent access to information.

Each skill includes a detailed reference guide, standards links, and manual
assistive-technology review procedures. Paired behavioral fixtures, negative
controls, and evaluation prompts support reproducible investigation and repairs.
See [the specialist evaluation guide](../SPECIALIST-EVALUATION.md) for coverage
and instructions.

## Versions and compatibility

The collection, packages, and plugin manifests are versioned 0.2.0. CLI, MCP,
and evaluation runner version identifiers match. The committed runtime bundles
have been rebuilt. Public evidence schemas remain at 1.0.0, and all seven
original skills retain their existing contents and individual versions.

Browser assertions provide scoped evidence; they do not establish screen-reader
speech, universal assistive-technology support, or WCAG conformance.
