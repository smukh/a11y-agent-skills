# Standards boundary

The default deterministic tag set targets axe rules associated by axe with WCAG
2.x A/AA, including WCAG 2.2 AA tags. The source of every machine mapping
remains `axe-core`; this project does not create new mappings.

Operational guidance links to canonical sources rather than reproducing
standards text:

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/) is the default reference target.
- [WAI-ARIA Authoring Practices](https://www.w3.org/WAI/ARIA/apg/) informs
  custom-widget behavior only when native HTML is insufficient.
- [WCAG-EM](https://www.w3.org/TR/WCAG-EM/) describes website conformance
  evaluation methodology.
- [ACT Rules Format](https://www.w3.org/TR/act-rules-format/) supports
  consistent test-rule design.
- [ARIA-AT](https://aria-at.w3.org/) provides assistive-technology
  interoperability evidence.
- [Section 508](https://www.section508.gov/manage/laws-and-policies/) and
  [EN 301 549](https://accessible-eu-centre.ec.europa.eu/content-corner/digital-library/en-301549-v32_en)
  may apply by jurisdiction and procurement context.

This repository is not a certification, legal-compliance service, legal opinion,
or substitute for testing with disabled users and real assistive technologies.
